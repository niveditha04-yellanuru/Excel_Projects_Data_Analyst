## 📊 Project Overview

The **Vrinda Store Annual Sales Analysis** is an end-to-end **Microsoft Excel Data Analytics project** focused on understanding sales performance, customer purchasing behavior, order trends, geographical performance, and sales-channel contribution.

The project transforms raw e-commerce sales data into an **interactive Excel dashboard** that helps answer important business questions and supports data-driven decision-making.

### 🎯 Business Objective

The objective of this analysis is to identify:

- Monthly sales and order trends
- Highest-performing months
- Customer purchasing patterns by gender
- Order status distribution
- Top-performing states
- Age-group purchasing behavior
- Highest-performing sales channels
- Best-selling product categories

The project uses Excel data preparation, analysis, PivotTables, charts, and dashboard techniques to turn raw data into actionable insights.
